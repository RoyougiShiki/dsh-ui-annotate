# 03 — 点元素 + 写说明 + 多条合并成一次填充

- **状态**: ready-for-agent
- **Blocked by**: #02
- **交付效果**: 连续标注 3 个元素、各写一句话 → 一次送进输入框 → 草稿里是 3 段结构化 markdown，顺序与点选一致。

---

## 做什么

- 标注条上出现说明输入框；写完「加入列表」，自动回到点选状态。
- 列表可删单条、可清空。
- 序列化纯函数 `entries → markdown`（见 `docs/adr/0004-markdown-payload.md`）。
- 按 Esc 退出标注模式，恢复页面 crosshair 与文字选择。

## 完成判据

- 序列化函数有单测（给定条目 → 期望 markdown）。
- 真实页面标注 3 条，草稿顺序与点选一致。
- 退出后页面元素样式无残留（`getComputedStyle` 与进入前一致）。
